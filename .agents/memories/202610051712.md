## 工具环境事实（可复用）

- **`gh sub-issue` 子命令在当前 gh 版本不存在**（`unknown command "sub-issue"`）。建父子关系只能走 REST：先 `gh api repos/{owner}/{repo}/issues/<n> --jq .id` 取数据库 id，再 `gh api --method POST repos/{owner}/{repo}/issues/<parent>/sub_issues -F sub_issue_id=<id>`。返回体是**父** issue。
- `gh issue view <n> --json ... --jq '{...}'` 在本机对该 jq 表达式报 `expected an object but got: array`（subIssues 字段结构不匹配），改用 `gh issue view <n>` 纯文本输出 + grep，或 `gh issue list` 更稳。
- 多行 issue 正文按 `docs/agents/issue-tracker.md` 要求写 UTF-8 文件后 `--body-file`；本轮写在系统临时目录，发布后已删除（仓库不存 issue 正文副本，与 #1–#12 既有做法一致）。
