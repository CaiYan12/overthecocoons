## 本机操作偏好（Windows + WSL 混合）

- **测试必须在 Windows 侧跑**（WSL node_modules 缺 rolldown Linux 绑定，`pnpm run check/build` 会挂）；PowerShell 输出中文乱码用「落盘 UTF-8-sig → `encode('gbk',errors='ignore').decode('utf-8',errors='ignore')`」修复。
- **CI 跟进用 `gh run watch <id> --exit-status --interval 10` 即时等待**（用户指定，不用 sleep 轮询）。
- **push 走 Windows 侧**：`~/.gitconfig` 把 github.com 凭据接到 `gh.exe auth git-credential`；WSL git 无 credential helper，直接推会失败。gh token 失效时需用户本人 `gh auth login -h github.com`。
- 按 `file:line` 跑 playwright 单测前先重新 `grep -n 'test("'` 取行号（编辑后行号会漂移，曾两次 "No tests found"）。
- 临时 probe 脚本用 `.cjs` 放项目目录内（`"type": "module"` + node_modules 解析），用完即删。
