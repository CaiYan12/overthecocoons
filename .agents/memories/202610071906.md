# 2026-10-07 19:06 — 长文页导航方案对齐

## 用户意图与现状核查

- 用户报告进入关于、原则、隐私页后无法从左栏点回时间线、来源；随后明确调用 `grill-with-docs` 探讨方案。
- 源码和线上关于页证明：长文页用本页目录替换全站导航，五个全站入口不在左栏 DOM 中，不是遮挡／层级或链接故障。
- `docs/ui-design.md` 的旧基线本就写了长文页切换为目录；这轮在对齐新的导航规则。
- 目录数量：关于 6、原则 6、隐私 5；现有章节高亮未实现，不能根据历史注释宣称支持。

## Q1–Q4 用户已确认

1. 左栏上下分组：五个全站入口固定顺序放上方，本页目录放下方；保留右栏现有结构。
2. 常规桌面短屏仅目录区内部滚动，优先保持全站入口可见。
3. 沿用现有宽度断点：桌面至少 1200px；平板经 MENU 换页；手机经 MENU 换页且目录在正文上方。
4. 极矮桌面中，当全站入口本身也放不下时，允许整栏滚动兜底，确保全部入口可达。

实施阶段用户补充确认：将兜底条件扩展为「全站导航与至少一行可操作目录不能同时容纳」，处理 430px 左右的空间冲突。最终实现与验收见 `202610071959.md`。

## 可复用经验

- 用户描述“点不到”时，应先核实入口是否存在于当前页 DOM；导航被目录替换与链接遮挡是不同原因。
- 讨论须区分全站导航、本页目录；同一侧栏中的可用高度是约束，不把估算当成实机尺寸。
