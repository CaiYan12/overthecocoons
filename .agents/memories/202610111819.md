# MENU跟随当前显示主题，取消明暗反转

2026-10-11 18:19。用户指出暗色页面打开MENU变成亮色，夜间刺眼。最新裁定覆盖旧菜单倒置配色；此前下拉／原路退出和光标动画不改。未提交、推送或部署。

- 源码事实：`.k-menu-surface`用`--ink`背景，dialog／条目使用`--paper`文字。深色token的ink为#F4EFE5，因此菜单会变亮。
- 修复：面板改为`--paper`背景，主文字与滚动条拇指为`--ink`，辅助文字为`--muted`，分隔线及按钮边框为`--rule`。当前项和hover保留accent。显式明暗及auto跟随系统统一继承页面token，未加独立菜单主题或依赖。
- 旧光标测试用面板背景等于墨色判读，改为与dialog文字墨色比较；透明覆盖边缘外仍是正常混合的当前主题墨色光标。
- 本地五配置MENU专项55/55通过（1.4m），含四种配色入退逐帧不反色、原导航延迟／快速开关／光标／停钟回收／短屏。独立Chromium明暗截图实际查看。check95文件0errors/0warnings与2旧hint，build66页、diff检查通过。未执行整站e2e、真机或线上验收。
