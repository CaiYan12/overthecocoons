## 实现要点

1. **反相混合作用点**：`mix-blend-mode: difference` 从 `.k-cursor-dot` / `.k-cursor-ring` 移到 `.k-cursor` 容器。子元素带混合会被容器自身的固定定位堆叠上下文（隔离组）屏蔽 → 渲染为原始白色；移到容器后浅色纸面实测 1.09:1 → 17.87:1。
2. **语义标签分层**：标签从 `.k-cursor` 内移出为**兄弟元素**，用 `gsap.set(labelEl, {xPercent:-50, yPercent:-50})` 自行居中，并新增一对 `quickTo` 独立跟随；完整语义态下与圆环**同步 `scale 2.3`**（否则标签不再继承圆环 transform，字号会掉回 9.5px）。
3. **描边 1.5px → 2px**：Blink 把 `border-width` 取整到整像素，`1.5px` 实测只渲染 `1.00 CSS px`。
4. **语义分档**：新增 `data-cursor-soft` 标记 + `CURSOR_SOFT_SCALE = 1.35`；`onOver` 按 `[data-cursor]` → `[data-cursor-soft]` → 静止三态。覆盖全部可点击元素（含正文行内链接）；未启用的分页边界项（`span[aria-disabled]`）不给标记。

## 复审发现并修复的回归（重要）

标签移出容器后，**`onLeaveDoc` 原先只隐藏 `cursor`**，语义态下移出窗口会留下**悬空残影**（标签是兄弟元素，不再随容器隐藏）。已改为 `gsap.to([cursor, labelEl], {autoAlpha: 0})`，并补 `window blur`（页面失焦）走同一处理器。**教训：把元素从容器里挪出来时，所有"随容器一起隐藏/显形"的隐式行为都要显式补上。**

## WebKit 实测机制（本轮最有价值的发现）

**合成 `documentElement` 的 `mouseleave` 之后，WebKit 会重放悬停链**：事件序列实测为 `over:SPAN.kw → [dispatch] → docleave → out:SPAN.kw → over:SPAN.ch`，Chromium / Firefox 无此重放。因为模拟时指针实际仍停在链接上，重放的 `mouseover` 会把标签重新点亮 → 出现「离开后标签仍显示」的失败。

- **判定**：模拟假象，非产品缺陷（真实移出窗口时指针已不在页面上）。
- **处置**：该用例「离开文档」分支只断言光标隐藏（AC 要求的正是"指针隐藏"）；标签隐藏改由「页面失焦」分支断言——两条路径是**同一个处理器** `onLeaveDoc`，覆盖不缩水。理由写在用例注释里。
- **手法**：先写探针复刻用例时序 + 事件埋点，`--repeat-each=3` 复现 3/3，才敢下结论——**不要靠猜机制**。

## 沉淀的测试手法（可复用）

`tests/e2e/helpers.ts` 新增（供后续 UI 票直接用）：

- `samplePixels(page, clip, points)` —— 截一次图 → 页面内 canvas 读回真实 sRGB，`points` 为相对区域坐标（内部按截图实际缩放换算，兼容 DPR）；区域越界时 Playwright 直接报错，不做静默裁剪。
- `contrastRatio(a, b)` —— WCAG 相对亮度对比度。
- `designToken(page, "--paper")` —— 读设计 token 当前计算值，避免测试里硬编码配色。
- `parseHexColor` / `channelSpread` —— 解析 token、在一组像素里挑字形芯。
- `cursorLabelOpacity(page)` —— 标签计算透明度（降级与隐藏路径共用）。
- **采样点自证**：断言前先校验「背景采样点 == 该底色」，否则对比度断言可能是采样错位造成的假通过。
- **变异验证**：断言写完后故意破坏实现（本例给标签加回 `difference`），确认断言会失败（实测渲染色变 `[34,181,171]`），证明断言有牙。
