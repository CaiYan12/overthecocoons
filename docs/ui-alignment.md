# UI 框架与功能对齐记录（2026-10-03）

用户已确认设计风格，要求将本轮结果保存到 docs 下备用。详细设计见 [ui-design.md](ui-design.md)。这些是讨论结果，不是实现/验收证据。用户决定：

- 技术为 Astro + Tailwind CSS + 原生交互脚本，保留 TypeScript/静态 GitHub Pages。
- 风格为报刊编辑型：强标题、细边框、较紧凑排版，暖纸白/墨黑/暗红，支持深色。
- 顶部直接放全部及 11 个主题，左导航/目录，中间单列阅读，右辅助信息。
- 临时主题筛选刷新重置。空主题可点击，显示真实空状态及查看全部。
- 时间线/详情左栏为功能导航；长文说明页切页内目录。
- 右栏为来源简介、数据更新时间/状态、项目原则、来源提交入口。
- 返回主站目标 https://caiyan12.github.io/；不参考主站 UI。
- 手机主题横向滚动，左导航进菜单，右信息移至正文下方。
- 首版新增本站热点详情，标题/简介/来源及已有字段，不转载全文。
- 标题进详情，卡片另有百度搜索入口。过期详情不保留内容，显示“条目已过期或不存在”及返回入口。
- 首版三态主题仅保存显示偏好，不记录阅读历史。
- 阅读工具为返回顶部、长文目录当前章节高亮、复制详情链接。
- 从详情返回恢复本标签页本次访问的筛选/页码/滚动；刷新或重新打开重置，临时位置仅内存。
- 丰富动效：页面 Reveal，卡片 Reveal + Stagger，手机菜单 Slide in + Fade in + Stagger。
- 卡片首次加载及主题/页码切换时触发；返回原位置不重播，不做滚动反复显现。
- 菜单关闭原路返回，快速操作可打断。减少动态效果/API 降级时保持功能可用。
- ui-design.md 的色号、字体、间距、断点和时长仍作为建议工程起点，落地时固化并实测。
- 搜索、随机漫游、订阅输出、多源对照仍留后续。
- 本轮不实现站点、不安装依赖、不创建远端 Issue、不提交、不推送、不部署。
