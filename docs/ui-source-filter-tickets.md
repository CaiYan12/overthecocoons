## 拆分依据

- 第一张让访客从真实入口完成「打开→多选→应用/取消→主题交集→分页/空态」，包含必要的视觉、响应式、动效、键盘和失败降级；不是把UI、数据与测试拆成技术层票。
- 第二张让访客完成「过滤后进入详情→浏览器返回继续阅读」，同时证明刷新/重开重置。当前阅读位置主要为页面模块内存，启动时手动关闭浏览器自动滚动恢复；不能把同文档主题切换或偶然BFCache命中视作跨文档恢复已具备。
- 两张均可独立演示与验收，各自包含相应测试、生产构建和文档证据。第一张完成不等于整个父规格完成；完整交付须两张均验收。
- 不设独立预重构票。筛选与渲染衔接的必要小调整随第一张完成，导航恢复衔接随第二张完成；没有证据需要一次宽泛改造。
- 唯一阻塞边：第一张 → 第二张。父规格是共同输入，不是要求先关闭的阻塞票。执行从无阻塞的第一张开始。
- 已发布为 #34 → #35：第二票正文的 Blocked by 引用 #34，并在 GitHub 原生 issue dependency 上登记 blocked-by（数字库 ID，非 issue 编号）。遵守不关闭或修改父 Issue 的边界。

## 1. 来源多选面板与时间线交集过滤

已发布：[Issue #34](https://github.com/CaiYan12/overthecocoons/issues/34)。无前置依赖。

### Parent

[Spec：公共时间线来源多选面板 #33](https://github.com/CaiYan12/overthecocoons/issues/33)

### What to build

访客可从首页、主题页及其分页的SOURCE来源标题打开选择面板，使用按钮型复选框分别选择六个订阅或全部来源。单选入口显示来源名，多个显示「多源聚合」和已选数量。勾选仅修改草稿，应用后按当前主题与已选来源交集更新公共时间线；所有取消入口撤销草稿。

桌面使用居中纸面模态，手机从底部上拉；字体、主题色、细线、勾选、轻阴影与280ms/160ms动效遵循父规格。实现主题双向联动、筛选后分页、真实空态及辅助信息同步，保留键盘/减弱动态/无脚本与失库降级。应用先完成面板退场，再执行既有列表切换和媒体交互重建。

本票可在单次页面阅读中独立演示完整筛选闭环；跨文档详情返回恢复由第二张交付。不得在本票引入与后续刷新重置冲突的长期存储或来源分享URL。

### Acceptance criteria

- [ ] 首页、主题页及其分页的时间线HUD具备入口；内容型HUD不扩展。默认全源，六个订阅分别呈现且名称、顺序准确固定，中新网频道不合并；无当前主题结果的源仍可选。
- [ ] 按钮型复选框有真实复选语义及至少44px点击高度；沿用本站纸面/字体/细边框，选中有强调色边界、勾号与轻底色，明暗主题均可辨认。
- [ ] 全选/部分/未选三态准确；草稿实时计数与外部已应用状态分开。零项草稿提示至少选一个并禁用应用。
- [ ] 打开从已应用集合开始；取消、关闭、Esc及真正遮罩点击丢弃草稿，面板内部点击不误取消；重开不保留已取消草稿。
- [ ] 应用非空集合仅提交一次；单选入口显示准确来源名，多个/全选显示「多源聚合」，辅文显示已选数量；等价集合只关闭，不重排、重播或改变原阅读位置。
- [ ] 来源取并集再与主题取交集，稳定次序、旧百度来源缺省归属和原收录时间保持；先筛选后分页，每页最多20条，不触发重新采集。
- [ ] 改变来源或主题保留另一维并到第1页、时间线开头；翻页与页码跳转使用交集有效范围，全部筛选入口共用同一结果口径。
- [ ] 日期目录、阅读位分母、分页及播报同步；空态真实描述组合无结果，分别提供仅放宽来源与仅放宽主题的操作。
- [ ] 桌面居中/手机底部上拉正确，面板沿原路退出可中断入场；280ms进退、160ms反馈/内容显现与短错峰有实际中间帧证据，应用在面板退场完成后才切换列表。
- [ ] 模态焦点约束、取消焦点返回、应用后焦点可见与结果播报可用；键盘不等待逐项显现，触屏无残留hover，减弱动态取消位移/错峰并保留轻淡入淡出。
- [ ] 与MENU互斥，锁背景滚动不造成宽度跳变，短屏面板内容可滚动；既有侧栏自然高度、光标/滚动条、MENU特殊动效裁定保持。
- [ ] 无JS或筛选初始化失败时入口可原生导航至来源说明页，静态阅读/主题/分页仍可用；无动效库时立即完成开合及应用。
- [ ] 快速开关、进入中取消、停钟与pagehide能可靠收尾，不残留遮罩/滚动锁、不误提交草稿、不重复应用；页面离开前不妨碍第二张恢复已应用状态。
- [ ] 复用已确认的公开页面测试缝及已有纯规则测试，使用可重复多源快照覆盖交集/空态/分页；不新增测试专用接口，不硬编码实时上游条数作为长期预期。
- [ ] 完成检查、生产构建、适当纯函数与浏览器回归；使用真实六源快照及独立生产产物验收320/390/768/1024/1440px明暗主题和窄/短屏。五配置专项按适用性执行，已有媒体尺寸/比例/揭示/高光与导航边界回归，证据与未验证项落档，模拟手机不称真机/FPS验收。

## 2. 详情返回恢复来源筛选与阅读位置

已发布：[Issue #35](https://github.com/CaiYan12/overthecocoons/issues/35)。阻塞于 #34。

### Parent

[Spec：公共时间线来源多选面板 #33](https://github.com/CaiYan12/overthecocoons/issues/33)

### What to build

读者在多选来源并应用主题、页码后进入条目详情，使用浏览器返回时继续原来的来源组合、主题、有效页码与阅读位置。普通刷新或重新打开页面恢复全部来源，主题与静态页码按实际URL初始化；不得把临时来源选择变成长期偏好或改变地址分享规则。

将恢复场景贯穿真实导航、筛选结果、渲染和阅读位反馈。恢复目标不存在时按既有有效范围原则回退并提示，明确区分浏览器返回、用户主动更改筛选和刷新，不假设所有返回都命中BFCache。

### Acceptance criteria

- [ ] 实际从已筛选时间线进入详情再浏览器返回，恢复已应用来源集合、主题、有效页码及原条目阅读位置；单源/多源入口名称、计数、日期目录和分页同步恢复。
- [ ] 恢复的是已应用条件，不包含取消或未应用草稿；重新打开面板与恢复后的正式条件一致。
- [ ] 分别验证缓存页返回与可控制的非BFCache跨文档返回；不得用同页主题切换或人工调用渲染冒充返回恢复。未能验收的路径明确记录，不宣称全部返回场景通过。
- [ ] 普通刷新和重新打开均重置全部来源；主题/静态页码按实际URL初始化，不从旧客户端主题状态冒充刷新后状态。
- [ ] 原阅读条目缺失或结果范围变化时，按现有恢复原则回退有效位置并提示，不制造无效页码或越过用户显式选页；主动更改筛选仍执行第一票的第1页/时间线开头语义。
- [ ] 不新增来源组合分享URL或静态路由，不长期保存来源偏好、不传送选择给服务端/统计；恢复异常不阻断静态阅读、基础导航或来源说明降级入口。
- [ ] 返回后无残留离场透明态、面板、滚动锁或失效光标/滚动条；原媒体尺寸、揭示/高光及焦点可见保持，恢复原阅读位置不无意义重播入场。
- [ ] 复用已有公开浏览器导航和位置纯函数测试，覆盖至少单源/多源、带topic、非首页页码、返回/刷新/重开及目标失效；不新增仅测试用接口。
- [ ] 完成检查、生产构建与针对性五配置回归；独立浏览器以真实六源产物验证返回和刷新两条路径，记录缓存条件、失败/跳过和未验证边界，更新完整规格交付状态。

- 第二票：详情返回、普通刷新/重开、恢复失败回退、临时状态边界及跨文档生命周期回归。
