# 条目详情页布局修正

2026-10-19：用户截图指出固定页头遮挡详情标题、摘要宽度未与图片对齐。本轮仅修正 `src/styles/kinetic.css` 的详情作用域，保留三栏、标题字号、版画比例、完整摘要及首页三行省略。

## 复现与原因

独立 IAB 在 1920px、真实首条详情、scrollY=0 实测：返回行 top=0，标题 top≈50.39px，固定页头 bottom=68px。详情没有说明页已有的正文顶部避让。图片宽820px，摘要受全局62ch限制仅≈581.73px，标题另受22em限制为660px；图片与摘要间距为0。

## 修正

- `.k-main:has(> .k-detail)` 顶部留出 `var(--header-height) + 32px`。
- `.k-detail` 统一最大版宽820px；标题、图片、摘要与元信息使用同一内容宽度。
- 标题到图片24px、图片到摘要24px、摘要到元信息16px；标题与摘要允许长串换行。
- 底部来源／复制操作使用可换行flex与独立行列间距，移除旧第二项左边距，避免窄屏换行缩进。

## 验证

- 真实页面1920/1440/1024/768/390/320px：返回行与页头净空32px；标题/图片/摘要/元信息宽度一致；图片下方间距24px；横向溢出0；完整摘要仍为300字。
- 实际最长73字标题在320px可完整换行，标题top≈142.39px，高于60px页头下沿，无横向溢出。
