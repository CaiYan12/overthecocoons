# 有界单行分页

2026-10-11：用户报告线上页码因条目增长换到多行，要求采用首尾／当前页窗口、省略号及输入跳转，完成后上线测试。使用 frontend-design，沿用暖纸／墨黑、衬线数字、暗红当前页下划线和细分割线，不引入新的组件库。

## 行为与实现

- `src/lib/pager.ts` 为静态 KPager 与客户端重绘共用的页码窗口和 HTML。宽栏显示前三／后三页与当前页前后一页；重叠合并、单个缺页直接补齐，总页数增长不扩展页码窗口。
- 分页栏自身为 CSS 查询容器：宽度 ≥660px 完整窗口，440–659px 首尾＋当前前后页，<440px 首尾＋当前页。保留上一页／下一页；始终一行，无分页内部滚动。每个数字只有一个链接、一个 `aria-current=page`，隐藏的密度项不占布局或键盘顺序。
- 跳转使用数字输入＋“跳转”按钮，原生校验必填、整数、1 至当前主题总页数；按钮和回车共享提交。当前页提交不重绘，其他页复用既有列表渲染、播报及焦点恢复，不新增历史或持久存储。
- 无 JS／增强初始化失败时跳转表单隐藏，真实页码链接继续可用；SSR 路径、主题与基路径保持原生降级。输入默认16px，避免手机编辑时因小字号缩放。
