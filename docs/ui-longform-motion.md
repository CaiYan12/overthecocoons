# 说明页编辑式动效

2026-10-11 用户指定 design-flow / animate，要求来源、关于、原则、隐私的正文和右栏增加完整 GSAP 编排，作为前端项目的展示部分。此决定覆盖这些新增动效的系统减动效分支；首页、目录和既有动效的偏好处理不在本次变更范围。

## 编排与视觉

| 层次 | 实现 | 时序 |
| --- | --- | --- |
| 页面标题 | 逐字遮罩、110%纵向升起、2°归位、淡入；暗红短线展开 | 550ms，逐字总错峰280ms |
| 章节标题 | 同一逐字语言，保留静止的章节锚点 | 550ms，逐字总错峰160ms |
| 段落与导语 | 下方18px升起、纵向裁剪揭开、淡入 | 标题入场开始后180ms起，550ms |
| 列表、定义列表、来源表格 | 保持原语义结构，第一层条目/行分层显现 | 按60ms错峰，总错峰上限280ms |
| 右栏 | 分隔线横向展开，随后标签、内容顺次揭幕 | 线280ms，内容550ms，各区块与内容错峰60ms |
| 右栏链接 | #32 统一继承色与逐行下划线，文字和命中盒固定；旧4px位移及重复规则线已移除 | CSS 700ms ease，仅精细且可悬停指针；焦点／减弱动态即时 |

除链接遵循[链接统一规则](ui-links.md)的 `--motion-link: 700ms` 外，揭幕时长复用 `--motion-slow` / `--motion-normal` / `--motion-fast`，统一 `power3.out`。新增运行时仍使用项目自托管 GSAP Core / ScrollTrigger 3.13.0，未新增依赖或插件。运动属性限定 transform、opacity、clip-path；临时 will-change 在收尾时清理。

## 行为约束

- 每章只播放一次。ScrollTrigger 使用 `top 88%` 入场；快速越章时完成该组，返回阅读不重播。不锁定滚动，不固定正文。
- `h1` / `h2` 内部字符运动，目录使用的 `section[id]` / `h2[id]` 本体不移动。右栏仅内部元素运动，完整自然高度继续撑开页脚。
- 首绘由独立 `data-oct-doc-pending` 门控。字体就绪与300ms预算竞速后建立初态，随后解除门控；1500ms脚本兜底已直显的页面不重新隐藏。
- 无JS、库加载失败、初始化失败保持原文直显。入场时以原生计时器武装1500ms收尾，不依赖 GSAP 的 onStart；暂停时钟后新章也可解除遮罩。
- 焦点进入未显现的正文/右栏内容时同步完成该组。pagehide 回收 context、ScrollTrigger、计时器、事件和包装DOM；缓存恢复保持静态可读。
- 标题拆字保留完整可访问名称；装饰字符、分隔线对读屏隐藏，正文和链接不拆字。
- 不拦截新增导航事件。已有目录240ms对称进退、连续选择接管、圆点光圈和无内部滚动裁定继续生效。

入口为 `src/client/longform-motion.ts`，四页由 `data-longform-motion` 标记。回归见 `tests/e2e/longform-motion.spec.ts`；本地验证和用户验收状态另记项目记忆，不将自动化结果当作实机或上线验收。

2026-10-11发布前补充：生产CSS会将毫秒token压缩成秒，运行时按实际ms/s单位换算，保持550/280/160ms时长。此前只复用开发服务器的验证未暴露此差异；本轮改用独立构建产物验证，失败、修复及最终提交／部署证据见[UI发布记录](ui-release-20261011.md)。
