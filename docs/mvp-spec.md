# 初版 MVP 规格

日期：2026-10-03。依据用户已确认的产品、UI 与 MVP-Q1–Q12。上轮已归档，本轮继续从 MVP-Q13 对齐未决工程选择。
本文是实施输入，不是已完成实现的证明。工程建议见 [架构](mvp-architecture.md)，原始问答结论见 [决定记录](mvp-decisions.md)。

## 目标与边界

“跳出茧房 Over the cocoons”以拓宽视野为主、日常资讯浏览为辅。提供所有访客共同的公共时间线，不按个人行为推荐，不人工精选单条内容。
首版一个来源即可公开：`https://rss.aishort.top/?type=baidu`。其内容是百度热点线索，外链通往百度搜索，不称为取得原文正文。来源自身已作热搜筛选，本站不展示热度、不用热度排序。

首版无账户、广告、行为统计、阅读历史、第三方字体 CDN。源图片允许按规则外链，但当前源未提供图片，使用本站占位图。不补抓搜索图片或新闻全文。
代码许可证已选 MIT，署名 `CaiYan12`；来源内容使用权与代码许可分开，公开展示许可已由维护者于 2026-10-04 核查裁定（非商业、获取信息目的，依据与署名见站内来源页）。

## 首版功能

| 页面/功能 | 已确认要求 |
| --- | --- |
| 公共时间线 | 单列，默认标题/简介/来源/收录时间/主题/图片区，每页最多 20 条 |
| 主题 | 全部＋固定 11 个主题，单选、全量筛选后分页，刷新重置；空主题可点并显示真实空状态 |
| 首源主题 | 新闻、社会；两者结果相同，其他主题暂空，不按标题猜细分类 |
| 热点详情 | 标题进入本站详情，展示简介/来源/已有元信息，不转载全文；独立百度搜索入口 |
| 过期详情 | 不生成过期内容页面；自定义 404 提示“条目已过期或不存在”并提供返回入口 |
| 来源页 | 区分原始平台与 Feed 服务提供者；只填核实信息，不猜地区或许可 |
| 说明页 | 关于、原则、隐私；长文页左栏目录与当前章节高亮 |
| 显示偏好 | 浅色/深色/跟随系统，仅主题偏好本地保存 |
| 阅读工具 | 返回顶部、复制详情链接、同次访问位置恢复 |
| 来源提交 | GitHub Issue 模板与入口，手工治理，不自动采纳新来源 |

搜索、随机漫游、订阅输出、多源对照仍属后续。

## 内容规则

1. 首源条目身份由来源 ID＋GUID 界定。不同 GUID 不因相似标题或相同搜索词自动合并。
2. GUID 缺失/冲突隔离输入并保留可信旧数据，不自动改用链接建立身份。
3. 同一身份、搜索关键词一致时可更新标题/简介，首次收录时间固定；关键词改变按身份冲突处理。
4. 首次收录发生于采集校验通过并成功保存权威状态；发布可能更晚，构建/部署失败不回滚已保存的收录事实。
5. 百度 feed 日期的业务含义未核实，不能当新闻发布时间；当前源按本站首次收录时间倒序。
6. 摘要优先用源摘要，缺失时取源提供正文的纯文本，最多 300 字；两者都没有时不编造。
7. 移除标题热度后缀，不展示推荐分、点击量或热度。
8. 当前网站与当前内容数据保持最近 7 天，以成功快照为基准，允许技术备份/版本历史，不提供站内旧内容阅读。
9. 保留窗口内的历史条目，不每天只用 feed 当前列表覆盖。身份记录与可读内容分离。
10. 仅排除来源明确标记的商业内容；当前源没有可靠商业标记，不承诺所有上游内容均无商业关系。

## 交互与视觉

沿用 [UI 记录](ui-alignment.md) 和 [设计规范](ui-design.md)：顶部主题、左导航/目录、中间阅读、右来源/状态/原则/提交入口。报刊编辑型，暖纸白、墨黑、暗红。
手机主题横向滚动、左导航进菜单、右信息移至正文下方。主站链接为 `https://caiyan12.github.io/`，不参考主站风格。
页面正文 Reveal；卡片 Reveal＋Stagger，首次加载/主题或页码变化触发，返回原位置不重播；手机菜单左滑入＋背景淡入＋条目错峰，可打断、原路退出。
减少动态效果或高级 API 不可用时保留功能。具体尺寸、字体回退、时长等仍是工程起点，需实际渲染核验。

本次阅读位置只在当前访问内存中，不写 localStorage/sessionStorage 或应用阅读历史。刷新/重新打开重置。内容变化时保留主题并尽量按原条目恢复，不存在则限制页码并提示变化。
无 JS 或脚本失败时标题、简介、详情、基本导航及简版条目目录可读；筛选、动态分页、动画可降级。

## 更新与失败

- 每日北京时间 08:00 触发，支持手动更新；不承诺正点完成。
- 定时/手动采集来源；main 推送只读 data 状态检查、构建、部署。build 不隐式抓源。
- 来源获取失败而可信旧数据存在：继续生成窗口内旧条目快照、清理过期内容、明确失败和最后获取成功时间。
- 数据保存失败不能认定新的首次收录已成立；构建/部署失败保留上一次成功网站。
- 原始时间、收录时间、尝试时间、成功获取时间、快照时间分别记录，不混称“更新成功”。
- 没有可信初始数据时不能伪造可用快照；初始化/恢复建议见架构。

## 验收矩阵

| 范围 | 必须验证 |
| --- | --- |
| 数据 | 同 GUID 重抓不刷新时间；内容修订保留时间；关键词冲突隔离；缺 GUID 不兜底造身份 |
| 窗口 | 7 天边界、旧条目累积、过期页面移除、身份记录不会因内容过期丢失 |
| 失败 | 来源失败保留可信旧内容；保存/构建/部署失败不伪报成功；首次初始化失败不造数据 |
| 路由 | 所有资源/链接带基路径；详情直达、刷新、过期 404；主站正常原生跳转 |
| 交互 | 先筛选后分页、空主题、详情与独立搜索入口、返回位置、内容变化后的回退 |
| 隐私 | 仅主题偏好持久化；无阅读位置持久存储、统计 SDK、广告或外部字体 |
| 可访问性 | 键盘焦点、菜单 Escape/背景/焦点返回、连续开合、动画取消、不遮挡可操作内容 |
| 降级 | 无 JS、脚本失败、减少动态效果、转场 API 不支持仍可读可导航 |
| 视觉 | 320/390/768/1024/1440px，浅/深色、长标题、缩放；截图与手机实机分开报告 |
