原型规格注记（评审用）

① 丝线 A/B 两版

版 A（解开编排）：红线自 Hero「茧」字缠绕（3 环，原型参数）→ 入场后解开 → 向下延伸 → 滚动至时间线时钉入左侧 rail（rail 由灰转红、钉点弹出）。顶部按钮切换，「↻ 重播」可重放。

版 B（静态连接）：列表 rail 常驻红线 + Hero 丝线自「茧」字底部穿出，无解开动画（本页默认，与降级态同构）。

缠绕目前整层置于字上；生产实现可将环线拆前后两弧分层，增强缠绕感——评审裁定项。线宽 / 环数 / 时长均为原型参数，评审后定稿。

② 丝纹选项（稳定 ID 派生）

版画区域以「构建期由条目稳定 ID 派生的确定性 SVG 丝纹」取代英文竖排词与出血序号，让版画携带每条独有信息；左下角等宽小字为 ID 前缀（演示用假前缀，实际为 64 位十六进制稳定 ID）。

③ 靛色站外信号

站外链接（查看百度搜索结果 ↗ 等）使用靛色；站内元素保持墨 / 红。对比度已实测（交接档口径）；本次复算 ≈7.7:1（浅）/ ≈8.0:1（深），均 ≥7:1。
