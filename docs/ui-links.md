# 链接视觉与指针统一

日期：2026-10-15。状态：已发布验收。功能提交 `7508fba` 已推送 main，CI/CD 构建与部署成功，Issue #32 已关闭；线上链接专项通过。集成分支为 `codex/link-interactions`，当前工作区已回到 main。

## 用户明确目标

- `a.ext`、`a.k-link`、`a.k-link.ext` 等链接常态无下划线，颜色继承。
- hover 时下划线从左向右展开，时长 0.7s。
- 目标链接的自绘指针统一使用 `LINK` 样式。

## 实施前核实的现状

- `src/styles/kinetic.css` 的全局 `a` 常态有下划线与强调色；`a.ext` 使用靛色，HUD 的 `.k-link` 有局部颜色及 hover 下划线。
- `src/client/longform-motion.ts` 为说明页 HUD 链接叠加 160ms 可逆动画：文字右移 4px，独立规则线展开。
- 标题是真实链接，目前用 `VIEW`；版画是 `div.k-media`，目前用 `OPEN`；复制链接是 `button.ext`，不能仅凭 `.ext` 纳入锚点范围。
- 主题与当前分页的线条表达选中状态；目录另有章节进度线。
- 来源页含可折行的长 URL；时间线标题也可能多行。MENU 链接包含编号与标签，标签与整个命中行的宽度不同。
- 旧外链靛色裁定见 `docs/adr/0005-silk-identity-design-baseline.md`；新规则确认后需标注覆盖关系。现有链接判定、语义及导航行为不因样式讨论而自动改变。

## 实现边界与验收依据

- 常态与 hover 颜色均遵循已确认的继承规则，不再按 `.ext` 单独染色；外链判定、目标 URL、`target`、`rel` 与已有外链箭头不因样式修改而改变。
- 普通文字链接常态无下划线；主题／分页选中标记、目录进度线作为已确认的状态信号保留。新增 hover 线不得覆盖、移动或重复绘制这些标记。
- 覆盖构建期与客户端生成的文字链接，含筛选、分页后新生成的标题和来源链接；精细指针命中后统一显示 `LINK`。版画 `OPEN` 与按钮原语义保持。
- 确认 hover 进入／离开两个方向的中间帧及 0.7s 完整行程，快速反向时接续当前状态；文字与命中盒保持稳定。
- 核查明暗主题、手机窄屏、来源长 URL、多行标题、MENU 标签及分页；不得因下划线导致断行变化、横向溢出或点击范围缩小。
