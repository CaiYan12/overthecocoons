# 首源身份采用来源 ID 与 GUID

2026-10-03，用户选择以来源 ID 与 feed GUID 共同界定首源条目，不以相似标题或相同百度搜索词合并不同 GUID。原文文章 URL 去重不适用于当前搜索线索源；此策略使首次收录与详情身份可重复恢复，避免把同一关键词的不同线索直接并为一条。GUID 缺失/冲突时隔离异常并保留可信旧数据，不自动用搜索链接创建替代身份。

当日完整 feed 核查有 100 条、无空/重复 GUID；但重复请求命中同一缓存版本，不能证明 GUID 跨更新长期稳定。用户后续确认同一身份搜索关键词改变视为冲突，关键词相同时允许修订标题/摘要并保留首次收录时间。具体算法尚待固化；身份及详情 URL 一旦公开，改变规则需要显式迁移。
