# 独立数据分支保存权威收录状态

2026-10-03，用户选择拟命名为 `data` 的独立分支保存首次收录记录、当前 7 天条目和采集状态；`main` 保存代码。这样跨日收录身份不依赖可丢失/可再生成的运行缓存，同时避免代码分支每天混入数据更新。替代方案是将每日数据直接提交到 `main`，用户未选择该方案。

这是已确认架构，不代表分支已创建或工作流已启用。用户后续确认保存成功即算收录，构建/部署失败不回滚首次收录；状态文件结构、并发和部署一致性仍是待固化的工程建议，工作流写权限须在实施中明确。当前网站/当前内容数据只保留 7 天，允许技术备份或版本历史，但不提供站内旧内容阅读入口。
