# Spec：公共时间线来源多选面板

日期：2026-10-19。用户通过 to-spec 推进已对齐方案，并明确确认测试边界及规格发布。本文是实施规格，不是功能完成或验证通过的证明。

## Problem Statement

公共时间线首页与各主题分类页右侧的 SOURCE 目前仅显示「多源聚合」，访客无法直接选择已接入订阅源。访客希望保留公共时间线的共同排序，在当前主题下浏览一个或多个明确来源的内容，并随时恢复全部来源。

本次页面已接入百度热点、中新网·社会、中新网·国际、中新网·东西问、极客公园、Solidot 六个订阅；同一平台的频道必须保持可分别选择。界面必须延续现有纸面、字体、细线、主题色与动效风格。

## Solution

将时间线 HUD 的来源标题增强为「选择来源」入口。单选时标题显示来源名称，选择两个及以上时显示「多源聚合」，辅文显示已应用的来源数量。首次进入默认全部来源。

桌面打开居中纸面模态面板，手机打开底部上拉面板。提供独立「全部来源」控件及六个按钮型复选框，交互参考外卖加菜多选，外观沿用本站风格。勾选只是暂选，点击「应用」并完成面板退场后才过滤时间线；取消、关闭、Esc 与遮罩均放弃草稿。

已选订阅源之间取并集，再与当前主题取交集，按原共同排序筛选后分页。更改主题或已应用来源时保留另一维，回到第1页。当前访问内保留已应用来源，进入详情后浏览器返回恢复筛选和阅读位置；刷新或重新打开重置全部来源，不长期记录来源偏好。

## User Stories

1. 作为时间线读者，我希望点击 SOURCE 下的标题打开选择面板，以便直接选择内容来源。
2. 作为主题页读者，我希望在当前主题下选择来源，以便缩小内容范围而不丢失主题条件。
3. 作为读者，我希望同时勾选多个订阅源，以便在同一时间线浏览这些来源的全部匹配内容。
4. 作为读者，我希望一键选择全部来源，以便恢复不限制来源的公共时间线。
5. 作为读者，我希望分别选择中新网·社会、国际与东西问，以便准确控制不同频道。
6. 作为读者，我希望只选一个来源时直接看到来源名称，以便辨认当前范围。
7. 作为读者，我希望选择多个来源时显示「多源聚合」和已选数量，以便知道当前采用组合筛选。
8. 作为读者，我希望按钮型复选框同时通过勾号、边框与底色表达选中，以便不只依赖颜色辨认状态。
9. 作为读者，我希望全选控件区分全部、部分与全不选，以便理解当前草稿范围。
10. 作为读者，我希望连续勾选时正文保持不变，以便完成组合后再统一应用。
11. 作为读者，我希望取消或关闭面板丢弃未应用修改，以便放心尝试不同组合。
12. 作为读者，我希望重新打开面板看到已应用的选择，以便继续调整真实生效的条件。
13. 作为读者，我希望暂时全不选时收到至少选择一个来源的提示，以便不会误应用一个没有来源的条件。
14. 作为读者，我希望来源更改后仍保留当前主题，以便无需重复选择。
15. 作为读者，我希望更改主题后仍保留已选来源，以便连续浏览同一来源组合的不同主题。
16. 作为读者，我希望先筛选后分页、每页最多20条，以便结果和页码一致。
17. 作为读者，我希望日期目录、阅读位计数和结果总数随筛选同步，以便辅助信息不会描述旧列表。
18. 作为读者，我希望无匹配内容时看到真实空态，以便理解这是筛选结果而非加载故障。
19. 作为读者，我希望空态可以分别放宽来源或主题，以便保留仍然需要的条件。
20. 作为读者，我希望打开详情再通过浏览器返回时恢复已选来源、主题、页码和阅读位置，以便继续阅读。
21. 作为读者，我希望刷新或重新打开后恢复全部来源，以便来源选择不变成长期内容偏好。
22. 作为桌面读者，我希望紧凑面板居中显示，以便集中处理六个订阅选项。
23. 作为手机读者，我希望从底部展开面板且按钮便于触摸，以便在窄屏完成同样的多选操作。
24. 作为深色模式读者，我希望面板继承当前主题，以便打开时不出现刺眼反色。
25. 作为键盘用户，我希望能够打开面板、勾选、应用、取消并返回可见焦点，以便无需鼠标操作。
26. 作为使用辅助技术的读者，我希望听到模态标题、复选状态、无效选择提示和过滤结果，以便理解界面变化。
27. 作为偏好减弱动态的读者，我希望取消空间位移和错峰，以便仍可清晰、稳定地完成选择。
28. 作为读者，我希望快速开关、动画缺失或停钟时仍能退出面板，以便不会被滚动锁或遮罩困住。
29. 作为无脚本或脚本失败环境下的读者，我希望入口仍能前往来源说明，且静态条目、主题与分页可用，以便继续阅读。
30. 作为读者，我希望反复应用同一集合时不重播或重排列表，以便避免无意义的界面跳动。

## Implementation Decisions

- 范围限于首页、首页分页、主题页及主题分页的时间线 HUD。说明页和条目详情的内容型 HUD 保持来源说明用途，不增加时间线筛选面板。
- 使用已有订阅身份和公开条目的来源标识；六个订阅分别选择，不根据来源网站域名合并频道。历史未显式携带来源标识的百度条目继续沿用已存在的兼容归属规则，详情身份和采集逻辑不变。
- 对当前六订阅提供独立的「全部来源」控件与六个复选项；选项顺序固定，不按热度、结果量或访问行为重新排序。来源在当前主题没有匹配内容时仍可选择。
- 显式区分已应用集合与面板草稿集合。打开复制已应用集合；勾选只修改草稿；取消丢弃草稿；应用提交非空草稿。不得让草稿数量或名称提前污染外部 HUD。
- 全选控件有选中、部分选中和未选三态：部分/未选时点击勾满六项；全选时取消可得到零项草稿。零项草稿显示提示并禁用应用，不产生零源的正式列表。
- 仅选一个来源显示准确来源名，多个显示「多源聚合」；全选也显示「多源聚合」。辅文以已应用集合表达「已选 N / 6 个订阅源」，面板草稿计数则随勾选实时更新。
- 来源之间取并集，随后与当前主题取交集，再按既有首次收录时间及稳定身份的确定性次序排列，最后分页。不得重新抓源、改变首次收录时间或引入个性化排序。
- 更改来源或主题均保留另一维且请求第1页；用户明确更改筛选时定位到时间线开头。分页和页码跳转始终使用交集结果范围。重复应用等价集合仅关闭面板，取消不改变原滚动位置。
- 列表、分页、日期目录、阅读位分母及相关播报共享同一交集结果口径。空结果明确说明来源与主题组合无匹配，提供「全部来源」与「全部主题」两个分别放宽对应维度的操作。
- 本次访问保留已应用来源；浏览器从详情返回时恢复来源、主题、有效页码与阅读位置。恢复内容不可用时沿用现有有效范围回退和提示原则，不越过用户显式选择页码。不得以仅同页切换的测试替代真实跨文档返回验证，也不得假设所有返回都会命中 BFCache。
- 刷新或重新打开时来源重置为全部，主题/静态页码遵循当前实际 URL 的既有初始化规则。不得新增来源分享 URL 或来源组合静态路由；不得使用长期偏好存储或把来源选择传送至服务端、统计服务。来源状态恢复不得改变刷新重置语义。
- 面板包含标题、关闭入口、全选、六个按钮型复选框、草稿数量/有效性提示及取消/应用。选项采用真实复选框语义和键盘操作，视觉点击高度至少44px，紧凑换行；细边框、直角或极小圆角，选中用主题强调色边界、勾号与轻底色共同表达。
- 配色与字体复用现有主题 token；面板采用94%纸色与6%墨色的同主题层次及克制轻阴影。自定义光标与滚动条继续可用；不增加字体请求、UI依赖、广告或统计。
- 桌面居中面板轻抬淡入，手机底部上拉；面板进退沿用280ms正常时长与现有缓出曲线，关闭沿原路返回且可中断入场。内容用160ms轻显现与短错峰，复选反馈160ms，语义状态立即变化；不添加弹跳或大范围模糊。
- 应用必须先完成面板退出，再复用既有列表出入场与媒体交互重建；取消不触发列表切换。保留已有媒体尺寸/比例、入场、局部高光和主题/目录动效。
- 使用原生模态焦点约束，面板与 MENU 不叠开，背景滚动锁不改变页面宽度。关闭、Esc及真正的遮罩点击均取消；点击面板内部不误触遮罩取消。短屏仅面板内容按需滚动，现有侧栏自然高度规则不变。
- 取消后焦点回来源入口；应用后焦点可见且不被回顶或重渲染留在不可见位置，并播报过滤结果。键盘操作不等待逐项显现；触屏不遗留鼠标 hover 状态。
- 新增面板遵循减弱动态：取消空间位移和错峰，保留轻淡入淡出；既有 MENU 的特殊动效裁定不因此改变或自动扩展到面板。
- 渐进增强必须在筛选能力成功初始化后才接管入口。无脚本或初始化失败时，保留可原生导航到现有来源说明页的入口与静态条目/主题/分页。
- 动效库缺失时立即完成开合与应用；暂停时钟、快速连续开关、退出中再次操作及页面离开均须有确定终态，能释放焦点和滚动锁。不得由旧回调重复提交或重新隐藏已显示的内容。

## Testing Decisions

用户已确认测试边界：以现有真实浏览器页面为主，从 SOURCE 入口完成选择、应用/取消、主题联动、分页、返回恢复与动效验收；仅为筛选及恢复规则补充已有纯函数测试，不新增仅供测试使用的接口。

- 主要测试缝是已构建站点的公开页面和真实交互。通过可访问角色/名称、可见内容、实际 URL、结果条目身份、页码、焦点、滚动和渲染中间帧验证行为，不绑定内部模块变量、私有状态机字段或补间数量。
- 复用现有主题筛选/分页/阅读位置/脚本降级、MENU焦点与快速开关、滚动条宽度稳定和媒体切换测试的模式；实现应扩展既有公共行为，而非暴露额外全局测试API。
- 单元测试只覆盖有业务区分力的纯规则：来源并集与主题交集、旧百度来源缺省、稳定次序、筛选后分页收敛及阅读位置恢复。复用已有时间线与位置恢复入口；必要的纯函数提取应服务生产复用，不为测试单独制造接口。
- 使用可重复、经校验的多来源测试快照证明组合、空交集和跨页行为；另以本地真实六源快照进行构建及独立浏览器验收。实时来源数量和文章标题不硬编码为长期断言，测试不依赖上游临时网络可用性。
- 至少覆盖单选、任意多选、全选、部分选中、全不选草稿、重开回滚、同集合重复应用、来源和主题双向联动、空态分别放宽及分页有效范围。
- 通过真实进入详情与浏览器返回证明筛选/位置恢复，分别验证普通刷新与重新打开会重置来源。覆盖可控制的非BFCache返回，或明确记录该边界未验收，不能仅以页面未卸载的场景宣称恢复完整通过。
- 动效断言包含实际入退中间帧、退出完成后才切列表、进入中取消、连续开合、缺库/停钟收尾、减弱动态和焦点可见。只看最终 open 布尔值或截图不足以证明动效方向与先后顺序。
- 覆盖明暗主题、320/390/768/1024/1440px、窄屏长来源名、短屏、键盘、触屏模拟、无脚本和初始化失败。沿用现有 Chromium/Firefox/WebKit/mobile-chrome/mobile-safari 五配置；指针专用场景按实际能力标注不适用，不把跳过计为通过。
- 完成项目检查、生产构建、适当纯函数与浏览器回归；测试运行期间冻结源码/文档，避免开发服务热更新干扰。独立浏览器验收生产产物，手机模拟、真实手机、FPS与线上证据分别报告。

## Out of Scope

- 新增或移除订阅源、修改采集频率、来源身份、日期语义、七天窗口及共同排序规则。
- 来源订阅账号、长期关注、个性化推荐、行为画像、访问统计或服务端偏好同步。
- 来源组合分享链接、组合静态页面、搜索、随机漫游、多源报道对照。
- 内容型HUD的筛选入口、全站UI重设计、既有MENU动效规则变更或依赖升级。
- 本次规格发布之外的实施票拆分、功能代码、Git提交/推送、部署，以及新增来源公开展示许可的替代裁定。
