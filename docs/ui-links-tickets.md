## 1. 统一全站文字链接的下划线动效与 LINK 光标

已发布：[Issue #32](https://github.com/CaiYan12/overthecocoons/issues/32)。无前置依赖。本地全量测试、专项矩阵与独立双轴复审已通过，详细交付和验证边界见 [本地实现与验收](ui-links.md)。下方保留发布时的原始验收清单，不表示已修改远端 checkbox。

以下为发布时的完整 Issue 正文；后续实施状态以远端 Issue 为准：

### What to build

将全站文字链接统一为常态无下划线、颜色继承；精细指针 hover 时，1px 同色下划线以平滑缓动在 0.7s 内从左向右展开，移出时在 0.7s 内从右向左收回。快速反向时从当前进度接续，文字与命中区域保持固定。

覆盖正文内外链、HUD、时间线标题、品牌、顶部主题、全站导航、本页目录、MENU、页脚、分页与详情返回。所有这些文字链接使用 LINK 自绘指针；标题原 VIEW 改为 LINK。版画 OPEN 与按钮光标语义保留。保留主题／分页的选中标记和目录进度线。

多行链接每行同时展开；MENU 只在文字标签下画线。取消说明页 HUD 的旧文字右移及重复规则线，使其服从同一套交互。保持已有导航、外链与渐进增强行为。

### Acceptance criteria

- [ ] 全部上述文字链接在常态无下划线，常态与 hover 均继承颜色；站外链接不再单独染为靛色，明暗主题均符合规则。
- [ ] hover 进入与离开分别完成 0.7s 完整行程，线宽 1px、继承文字色；实际中间帧可验证左右方向，快速反向无跳变或强制归零。
- [ ] 来源长 URL 与多行标题每行同时展开下划线；保持原有断行与排版，无横向溢出，文字与命中盒不因动效移动。
- [ ] MENU 下划线只覆盖文字标签，不跨编号和整行空白；取消说明页 HUD 原有 4px 文字位移，不出现重复线。
- [ ] 所有纳入范围的文字链接使用 LINK 指针，包含标题原 VIEW；版画仍使用 OPEN，按钮仍使用原有光标语义。
- [ ] 主题／分页的当前选中标记和目录进度线保持有效；新增 hover 线不覆盖、移动或重复绘制这些标记，相关导航与分页交互保持正常。
- [ ] 静态构建与客户端筛选／分页后新生成的标题和来源链接应用同一规则，不出现首次正确、更新后退回旧样式或旧指针的问题。
- [ ] 键盘 focus-visible 立即显示完整下划线并保留焦点轮廓，Enter 导航可用；触屏没有残留 hover；系统请求减弱动态时下划线即时显示／隐藏。
- [ ] 无 JS 时链接仍可读、可聚焦、可原生导航；外链目标、打开方式、安全关系属性、外链箭头及既有复制链接行为保持正确。
- [ ] 更新与新裁定冲突的外链颜色、指针及 HUD 动效文档／断言；以有区分力的样式、动效中间帧、指针命中与动态内容回归覆盖上述行为，完成项目检查、构建及适当测试。
- [ ] 使用独立浏览器核查生产构建的明暗主题、桌面与窄屏、多行内容、MENU、焦点及快速移入移出；记录实际证据与未验证边界，自动化手机配置不表述为真机验收。
