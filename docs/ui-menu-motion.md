## 审查与方案

| 原实现 | 新实现 | 原因 |
| --- | --- | --- |
| dialog 本身 opacity 0→1，没有进入方向 | 不透明 `.k-menu-surface` 从 yPercent -100→0，自顶部覆盖 | 进入路径明确，覆盖边缘始终清晰 |
| 条目 500ms + 50ms 逐项交错，退场使用 power2.in 并再次逐项等待 | 面板入退均为 `--motion-normal` 280ms、power3.out；内容 -12px→0 与 opacity 同步，使用 `--motion-fast` 160ms，组内总交错40ms | 高频开合响应可控，收起沿进入路径返回 |
| 普通链接立即跳转；说明页还可能触发左目录退场 | MENU 自己接管同源链接，280ms 上收完成后重放一次真实链接 | 不截断菜单，不串联第二段目录退场 |
| 主题点击时先改变正文，同时菜单退出 | 先退出，再重放主题点击；时间线沿用客户端筛选，说明页沿用静态主题链接 | 显示层与内容切换顺序一致 |

目的为偶尔打开的导航层提供空间关系与明确状态反馈。保留原生 dialog、字号、双栏及手机单栏；不新增依赖。配色按后续裁定跟随页面主题，见下方修复记录。用户此前完整动效裁定沿用到 MENU：这套编排不按 reduced-motion 缩减；旧主页与目录门控不改。

## 交互约束

- `closed → opening → open → closing → closed`。关闭可打断入场，使用当前位移继续退出；同一退出中重复点击不创建新时间线，最后目标接管。
- 点击当前站内页面只收起，不刷新。关闭按钮或 Esc 清除待跳转，收起后留在当前页面。
- 修饰键、中键、下载、外部目标及新窗口链接保留原生语义，不延迟或吞掉。
- showModal 后立即聚焦关闭按钮；原生焦点约束保留。不使用 visibility 隐藏关闭按钮；普通关闭返回 MENU 焦点且不滚动页面。
- dialog 外壳不参与 transform。自定义光标迁入它的顶层，而不是移动面板，坐标保持视口参照。动画边缘外的光标用当前主题墨色，解决透明 dialog 无法反相混合外部纸面的可读性问题。
- 菜单展开期间锁住背景整页滚动；退出及 pagehide 恢复先前 overflow。后续使用自绘覆盖式纵向滚动条，增强状态无占位槽；保留短屏菜单的原生内容滚动。这不影响已裁定的左右侧栏自然撑开布局。
- 缺 GSAP 时立即显示／关闭并继续链接。入场和退出各有1500ms原生定时器兜底，不依赖 GSAP 时钟。回收必须杀掉时间线及独立 set 补间，并强制执行 clearProps 使变换缓存失效；否则父时钟恢复会重新写回隐藏初态。
- pagehide 取消待跳转、关闭 dialog、移回光标、清理所有 MENU 样式和滚动锁。生命周期测试包含合成 pagehide，不声称它等同真实 BFCache 命中。
