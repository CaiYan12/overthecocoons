# 跳出茧房 Over the cocoons — DESIGN.md

日期：2026-10-03。状态：用户已确认设计风格及本轮讨论选择，保存到 docs 下备用；当前未实现站点。
本轮用户已决定布局、功能、技术组合与动效类型。具体色号、字体回退、间距、断点和时长保留为建议工程起点，后续落地时固化并实测；它们不是实机验收结果。
按用户选择定制报刊、暖纸白/墨黑/暗红与三栏布局；design-brief 的预设 token 表未覆盖这套组合，本规范优先遵守用户选择。
产品、来源、排序和保留基线见 [product-alignment.md](product-alignment.md)，领域术语见 [GLOSSARY.md](../GLOSSARY.md)；本轮新增 UI 范围见 [ui-alignment.md](ui-alignment.md)。

## 1. Visual Theme & Atmosphere

- 报刊编辑型：强标题对比、细边框、较紧凑资讯排版。
- 暖纸白、墨黑、暗红强调；支持浅色/深色/跟随系统。
- 顶部主题导航、左导航/目录、中间单列阅读、右辅助信息。
- 出处、收录时间、搜索去向形成一致的信息层级，表达真实来源关系。
- 页面正文揭幕、卡片揭幕采用同一视觉语言；顶部和侧栏框架稳定。
- 返回主站目标为 https://caiyan12.github.io/；用户明确不参考主站 UI。
- 样本必须标明是设计示例，不伪造新闻、阅读统计或推荐评分。

## 2. Color Palette & Roles

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| paper | #F8F5EC | #191816 | 页面底色 |
| surface | #FFFDF7 | #23211E | 辅助区与控件表面 |
| ink | #211E1B | #F4EFE5 | 主文字 |
| muted | #655F58 | #BEB5A8 | 次级文字 |
| rule | #9C9387 | #716A61 | 装饰性细分割线 |
| accent | #8F262B | #E18B86 | 当前主题、链接、焦点与关键操作 |

- 使用统一 tokens；交互边界用 muted / accent，不能只用装饰性 rule。
- 选中主题以颜色、下划线/字重及语义状态共同表达。
- 普通文本与 paper / surface 的 12 组对比度已计算，最低 5.78:1；这不是完整 UI 无障碍验收。
- 实际来源图片不受界面品牌调色限制。

## 3. Typography Rules

建议参数：

| 角色 | 字体回退 | 字号/行高 |
| --- | --- | --- |
| 品牌、页面标题 | serif | 32–40px / 1.2，700 |
| 卡片标题 | serif | 22–26px / 1.35，600–700 |
| 正文与简介 | system-ui, sans-serif | 16px / 1.6，400 |
| 导航与控件 | system-ui, sans-serif | 14–16px / 1.4 |
| 出处与时间 | system-ui, sans-serif | 13–14px / 1.5 |

- 首版使用系统字体，不访问第三方字体 CDN。
- 系统字体因设备而异，中文字形和长标题须在实际浏览器复核。
- 标题保留为文本；简介默认显示，最多 300 字。
- 本轮没有选择特定外部字体或确认字体文件分发许可。

## 4. Component Stylings

### 顶部与两侧

- 顶部直接展示“全部”及固定 11 个主题：新闻、科技、文化、科学、社会、经济、环境、健康、教育、艺术、哲学。
- 主题仍为临时筛选，不创建独立主题 URL；刷新回到全部。
- 从其他页面点击主题，回到时间线并应用本次选择；SPEC 需固化并验证这个跨页行为。
- 空主题仍可点击，显示真实空状态与“查看全部”。
- 首源默认新闻、社会，两者结果相同；其他主题暂空。
- 左栏：时间线、来源、关于、原则、隐私等功能导航。长文说明页切换为页内目录；时间线/热点详情保留导航。
- 右栏：来源简介、真实数据更新时间/状态、原则入口、GitHub 来源提交入口。
- 返回主站入口清晰可见。首版右侧未纳入天气、音乐等其他元件；无广告、无访问统计约束继续保留。

### 时间线与详情

- 时间线中间单列，默认显示标题、简介、来源、收录时间、主题、小尺寸图片区域。
- 用紧凑间距、细分割线和清楚层级组织条目；建议直角或极小圆角。
- 点击标题进本站详情；卡片另有“查看百度搜索结果”入口。
- 缺图、失败或明确禁止外链时保留图片区域，用本站占位图；首源不补抓搜索图片。
- 原图完整展示，不裁剪。筛选全部保留内容后分页，每页最多 20 条。
- 新增详情页：标题、简介、来源及已存在的时间/主题，不转载全文、不补造正文。
- 详情可返回时间线、复制链接。超出 7 天窗口后不保留内容，显示“条目已过期或不存在”和返回入口。
- 详情路径与稳定 ID 由 SPEC 根据实测数据确定。

### 工具与状态

- 返回顶部、长文目录当前章节高亮、复制详情链接。
- 复制实际成功才提示已复制；失败提供手动复制方法。
- 三态主题模式可本地记忆；主题存储用项目专属 key，具体名称由 SPEC 记录。
- 从详情返回时间线时，恢复当前标签页本次访问的主题、页码、滚动位置。
- 临时位置只在内存，不写 localStorage / sessionStorage 或阅读历史；刷新/重新打开重置。
- 持久化仅用于主题偏好。
- 展示真实更新时间与已知状态；旧静态页面不能预知部署后失败，不将“较旧”直接称为“抓取失败”。

## 5. Layout Principles

```text
返回主站 / 项目标识 / 全部＋11 个主题 / 显示模式
────────────────────────────────────────────
左：导航或目录 │ 中：单列时间线/详情 │ 右：来源与更新
────────────────────────────────────────────
阅读工具与页脚
```

建议起点：

- 外框最大 1200px；页面安全边距 16–24px。
- 桌面左栏 160–180px，右栏 200–220px，中栏分配剩余空间。
- 栏间距 24px；区块间距 48px；内容内边距 16px / 24px。
- 正文宽度不足时提前切换移动布局，不强行挤出三栏。
- 顶部/侧栏停留策略需避免遮挡标题和焦点；过长目录在真实内容下验证。
- 时间线不拆成多列新闻流。

## 6. Depth & Elevation

- 细边框、分割线、文字层级为主，常规内容不依赖装饰阴影和大圆角。
- 模态菜单背景遮罩明确层级，揭幕遮罩只短时用于过渡。

### 已选择动效

| 场景 | 效果 | 触发与限制 |
| --- | --- | --- |
| 页面切换 | Reveal / Page transition | 遮罩揭开新正文，顶部/侧栏框架稳定 |
| 卡片进入 | Reveal + Stagger | 边界揭开、错峰进入 |
| 卡片触发 | 首次加载、切换主题/页码的新内容 | 返回原位置不重播，不做滚动反复显现 |
| 手机菜单 | Slide in + Fade in + Stagger | 左抽屉滑入、背景淡入、条目轻错峰 |
| 退出/打断 | Interruptible animation | 原路退出，连续操作可取消或反向当前动画 |

建议参数：

- 页面 250ms；卡片 220ms，错峰 40ms、总错峰延迟上限 160ms。
- 抽屉 260ms；背景 180ms；菜单项 160ms，错峰 30ms。
- 进出曲线：`cubic-bezier(0.23, 1, 0.32, 1)`。
- 抽屉曲线：`cubic-bezier(0.32, 0.72, 0, 1)`。
- 页面与卡片要编排，避免卡片在页面遮罩下已播放完。
- 动效不阻塞点击、关闭、复制和连续筛选；功能状态及时生效。
- 键盘反馈及时，焦点进入遮罩区域时立即解除遮罩。
- 减少动态效果时取消空间移动/揭幕队列，保留简单反馈，内容可读。
- API 不支持时正常导航/直接更新；不以动画可用为核心功能前提。
- 参数需在浏览器实测；当前不声称特定 FPS 或流畅度已通过。

## 7. Do's and Don'ts

- 遵守 GLOSSARY.md 的产品/来源/隐私规则及 /overthecocoons 子路径。
- 使用真实按钮/链接语义，键盘焦点清楚可见。
- 手机模态导航以原生 dialog 为起点；焦点进入/返回、背景 inert、Escape 和滚动锁定均需实测。
- 动画结束、取消和页面离开都清理状态与监听器。
- 主站 URL 保持用户提供的实际值，不复刻主站风格。
- 不编造摘要、题图、发布时间、商业标记或统计。
- 不因丰富动效改排序、默认内容或阅读历史规则。
- 不直接复制官方示例中与本规范不同的时长、曲线或视觉效果。

## 8. Responsive Behavior

- 起点断点 640 / 768 / 1024 / 1280px；三栏临界点按正文可读宽度复核。
- 手机：主题横向滚动，左导航进菜单，右信息到正文下方，中间单列。
- 选中主题保持在横向导航可见区域。菜单有清楚关闭入口。
- 触摸目标建议至少 44px；长标题、缩放与窄屏不造成整体横向溢出。
- 图片/占位保持稳定空间，原图保留比例。
- 后续至少检查 320 / 390 / 768 / 1024 / 1440px，浅/深色、键盘、减少动态效果。
- 区分源码检查、浏览器检查与手机实机验收。

## 9. Agent Prompt Guide

- 技术：Astro + TypeScript + Tailwind CSS + 原生交互脚本。
- 用 Astro 客户端导航支持同次访问内存与转场；生命周期与状态恢复须实现/测试，不能声称自动完成。
- 动效起点为 CSS、Web Animations API、Astro 转场；模态起点为原生 dialog。
- 当前未选择 React、shadcn/ui 或额外动画库。新增依赖先说明必要性并查证文档。
- 版本与命令实施前核实，本轮未安装依赖或选择版本号。
- 本轮新增首版功能：详情页、三态主题及仅主题本地保存、阅读工具、同次访问位置恢复、页面/卡片/菜单动效。
- 搜索、随机漫游、订阅输出、多源对照仍留后续。
